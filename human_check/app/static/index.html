Instructions

You will see one video frame from a head-mounted camera worn by a young child, and one utterance (by the child, a caregiver, or someone else) transcribed from that same moment. Speech is often not about anything on screen.

Question 1. How strongly does the utterance refer to a concrete, physical object that is actually visible in this frame?

  • No visible referent — small talk, the object is absent or unidentifiable, or the utterance is not about a concrete object.
  • Present but small / partial / one of many — the named object is present but small, partial, or one of many.
  • Clearly present — the utterance clearly names a prominent, plainly visible, central object.
  • Can't tell — the frame or the utterance is unusable (black, blurred, unintelligible). Use sparingly.

Question 2. If the answer is not "no", type the single visible object referred to, as a lowercase common noun (e.g. cup, dog).

Three conventions (they match how the automatic annotation was scored, so please follow them even if they feel arbitrary):

  • People count as objects. "Hi, Dad" with Dad in view → clearly present, referent dad. Same for baby, hand, etc.
  • Names and nicknames refer to whatever they name. "Leave Pepper alone" with the dog in view → referent dog; "your Jessie toy" → doll. If you can't tell what the name refers to, choose no visible referent.
  • Sound words count when the thing making the sound is in view. "Quack, quack" with a toy duck in view → referent duck; with nothing duck-like visible → no visible referent.
